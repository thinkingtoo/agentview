# 14: Copy button on commands guessed in the session line

**What to build:** A command a session leaves for the person in its session line (`ask`) gets a copy button too. The session-line hook stays unchanged, so `ask` is free text: the roster guesses the commands in it. Owner's choice, 2026-10-19: "Guess commands in the text": text in quotes, or after a `$`, that reads as a command is offered with a copy button; it will sometimes guess wrong, and that is accepted. A guess never answers the session and never runs anything. Prose without a command shows no button.

**Amended by the owner, 2026-10-19:** the hook is no longer unchanged. `hooks/turn_line.py` `ASK` now carries two more sentences. One says where a command goes: inside double quotes, or after `"$ "` at the end of the ask, within the single-quoted text (the guesser's evidence is a command the session marks, not a command it names bare). The other says that a single quote in either field is written `'\''`, because both fields sit inside the hook's own single quotes. The ask stays free text and the roster still guesses; the hook only asks, and a session that does not follow it still gets the same guess as before.
